\# Weather App 



A Python-based weather application that fetches live weather information using the Open-Meteo APIs.



\## Features

\- Search weather by city name

\- Display temperature in Celsius

\- Show weather conditions

\- Display US Air Quality Index (AQI)

\- Handle invalid city names and API errors



\## Technologies Used

\- Python

\- Requests library

\- Open-Meteo Weather API

\- Open-Meteo Geocoding API

\- Open-Meteo Air Quality API



\## How to Run

1\. Install Python.

2\. Install the required library:

&#x20;  `py -m pip install requests`

3\. Run the application:

&#x20;  `py main.py`
